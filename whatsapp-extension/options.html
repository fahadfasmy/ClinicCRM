C

WhatsApp capture

Connects WhatsApp Web on this computer to Clinic CRM.

The address you use to open the CRM, without a page name.

Create one in the CRM under Setup → WhatsApp Capture. Use a separate key per computer.

Good to know

  • Capture only runs while web.whatsapp.com is open in this browser.
  • The extension never sends WhatsApp messages or changes your chats.
  • Numbers that are already in the CRM are never added twice.
  • Keep WhatsApp Web in English so unread chats are detected reliably.
